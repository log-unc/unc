Test your environment logger.

Log-Unc runs 1248 checks against the Roblox API and reports how much of it your sandbox reproduces correctly. A real Roblox client scores 100% with zero failures, so every failed check is a gap in your logger.

01 — Run

Copy the loadstring or the source from the Script tab and run it in your environment logger.

02 — Convert

Paste the console output into the Submit tab. It keeps only the failures and skips, so the result file stays a few kilobytes.

03 — Publish

Add the generated file to loggers/ and open a pull request. Merging it publishes the result.
