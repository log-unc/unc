Test your environment logger.

Log-Unc runs 1200 checks against the Roblox API and reports how much of it your sandbox reproduces correctly. A real Roblox client scores 100% with zero failures, so every failed check is a gap in your logger.

01 — Copy

Grab the script from the Script tab. One file, no dependencies, and a single optional HTTP probe.

02 — Run

Execute it in your environment logger. The final lines print the score, every failed check and the collected metrics.

03 — Submit

Open a pull request with your output as a JSON file. The Submit tab builds that file for you.

    How it works: every file in site/loggers/ is parsed at build time, so a merged pull request publishes the result automatically. The build rejects malformed files, duplicate names and outputs with no recognisable checks. Identifying metrics such as UserId, DisplayName and ClientId are stripped before anything is published.
